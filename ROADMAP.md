# Seed Studio roadmap

We aim to release useful improvements every month. This is a living plan, and priorities can change with testing and community feedback. Follow GitHub Releases for shipped updates and use feature requests to shape upcoming work.

## Public release

- [x] Publish the application source with the MIT license.
- [x] Document Mac setup and bring-your-own-key usage.
- [x] Add Seedance 2.5 Flash alongside Seedance 2.5.
- [x] Refresh the app icon.
- [x] Add automated Mac checks and a manual release workflow.

## Next priorities

- [ ] Improve first-run setup and model-access diagnostics.
- [ ] Add reusable community storyboard templates and examples.
- [ ] Expand model capability checks as provider APIs evolve.
- [ ] Improve keyboard navigation and canvas accessibility.
- [ ] Validate wider Mac compatibility and signed distribution.

## Exploring

- [ ] Shared projects and collaborative editing on an optional self-hosted team backend.
- [ ] More export formats and creative-app integrations.
- [ ] Additional provider adapters.
- [ ] Windows support.

Each monthly release will link its completed changes and contributors in `CHANGELOG.md`. Suggest a concrete use case and expected result through the repository's feature-request form.
